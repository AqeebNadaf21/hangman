# hangman
CodeAlpha Python Programming Internship

Hangman Game using Python

Developed a console-based Hangman game using Python that provides an interactive word-guessing experience. The game randomly selects a word from a predefined list and challenges players to guess the hidden word one letter at a time within a limited number of attempts. The objective is to correctly identify all letters in the word before exhausting the available guesses.

The application utilizes Python's random module to select words dynamically, ensuring a unique gameplay experience each time. Core programming concepts such as loops, conditional statements, lists, and string manipulation were implemented to manage game logic and user interactions. The game tracks guessed letters, displays the player's progress using placeholders for unguessed characters, and updates the interface based on correct or incorrect guesses.

Additional features include validation for previously guessed letters, real-time feedback on player actions, attempt tracking, and win/loss conditions. The game ends when the player successfully guesses the word or uses all available attempts, after which the correct word is displayed.

This project helped strengthen fundamental Python programming skills, including problem-solving, algorithm design, user input handling, and control flow management. It also provided practical experience in developing interactive command-line applications and implementing game logic efficiently.

Technologies Used: Python

Key Skills: Python Programming, Random Module, String Manipulation, Conditional Logic, Loops, Lists, User Input Handling, Problem Solving, Game Development, Command-Line Applications.
